# Zenvy Shop

A full-stack e-commerce web application built using PHP, MySQL, JavaScript, HTML, and CSS.

## Features
- User Registration & Login
- Product Management
- Shopping Cart
- Order System
- Razorpay Payment Integration

## Tech Stack
- PHP
- MySQL
- HTML, CSS, JavaScript

## How to Run
1. Import database.sql into MySQL
2. Place project in XAMPP htdocs folder
3. Run on localhost
